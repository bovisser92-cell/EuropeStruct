2. Welche personenbezogenen Daten verarbeiten wir?

Wir verarbeiten ausschließlich Daten, die Sie uns selbst über das Kontaktformular auf dieser Website zur Verfügung stellen:

  • Vor- und Nachname
  • E-Mail-Adresse
  • Telefonnummer (optional)
  • Firmenname (optional)
  • Der Inhalt Ihrer Nachricht

Wir erheben keine besonderen Kategorien personenbezogener Daten (wie Gesundheitsdaten oder Sozialversicherungsnummern).

4. Wie lange speichern wir Ihre Daten?

Wir speichern Ihre personenbezogenen Daten nicht länger als für den Zweck erforderlich, für den sie erhoben wurden. Kontaktanfragen werden so lange gespeichert, wie es für die Bearbeitung Ihrer Anfrage erforderlich ist, danach maximal 12 Monate, es sei denn, es besteht eine laufende Geschäftsbeziehung oder eine gesetzliche Aufbewahrungspflicht.

5. Geben wir Ihre Daten an Dritte weiter?

Wir verkaufen Ihre personenbezogenen Daten niemals an Dritte. Das Kontaktformular auf dieser Website ist mit dem Formulardienst Formspree (formspree.io) verbunden, der die eingereichten Daten in unserem Auftrag als Auftragsverarbeiter verarbeitet. Weitere Informationen zu deren Datenschutzerklärung finden Sie unter formspree.io.

Darüber hinaus verwendet diese Website Google Fonts (Schriftarten). Dabei kann Ihre IP-Adresse von Google verarbeitet werden. Google Fonts wird von einem externen Server von Google geladen. Weitere Informationen finden Sie in der Datenschutzerklärung von Google.

7. Ihre Rechte nach der DSGVO

Sie haben in Bezug auf Ihre personenbezogenen Daten folgende Rechte:

  • Auskunftsrecht — Sie können erfragen, welche Daten wir über Sie verarbeiten.
  • Recht auf Berichtigung — Sie können unrichtige Daten korrigieren lassen.
  • Recht auf Löschung — Sie können die Löschung Ihrer Daten beantragen.
  • Recht auf Einschränkung der Verarbeitung — Sie können die Verarbeitung vorübergehend einschränken lassen.
  • Recht auf Datenübertragbarkeit — Sie können Ihre Daten in einem strukturierten Format anfordern.
  • Widerspruchsrecht — Sie können der Verarbeitung auf Grundlage berechtigten Interesses widersprechen.

Um Ihre Rechte auszuüben, kontaktieren Sie uns unter info@europestruct.com. Wir antworten innerhalb von 4 Wochen auf Ihre Anfrage.

EuropeStruct nimmt den Schutz Ihrer personenbezogenen Daten ernst und trifft angemessene technische und organisatorische Maßnahmen, um Missbrauch, Verlust, unbefugten Zugriff und andere unerwünschte Handlungen zu verhindern. Unsere Website wird über eine gesicherte HTTPS-Verbindung bereitgestellt.
